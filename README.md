# Commit
En commit är en sparad vrsion av ändring i Git med ett meddelande som beskriver vad jag har gjort.

# Git vs GitHub
Git är  verktyget som sparar versioner lokalt på datorn, medan GitHub är en webbplats där jag kan publicera och dela mitt repo online.

# Synlig medverkan

det betyder att commits visar vem som har gjort ändringar och vad som har ändrats i projeket.
